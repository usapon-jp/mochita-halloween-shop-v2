# もちたの小さな雑貨とおやつのお店（ハロウィン・新しいもちた版）

Three.js で作った、もちたの小さなお店の箱庭です。スマホでもパソコンでも開けます（無料の GitHub Pages で公開）。

## あそびかた
- **タップ**: もちたが、タップした場所まで歩いてきます。カウンターは ぴょんと飛び越えます。
- **ドラッグ**: カメラを回す／**ピンチ**: 拡大・縮小／**2本指**: カメラを平行に動かす。
- **もちたボタン**（右下）: もちたモード。左下にスティックが出ます（絵は動きません）。画面の左側をなぞった向きに、もちたが歩きます。右側のドラッグでカメラを回します。ジャンプ・ダッシュもできます。
- **タグ**（左上）: エリアの切りかえ。もちたモード中は、お店のなか／お店のまえ／お庭へのワープと、集めたお菓子のワープ地点が出ます。
- **お菓子さがし**: お店とお庭に、ハロウィン柄のプレゼントボックスが6つ かくれています。近づくと開いて、お菓子が出てきます。好きな場所に置くと（置ける所は緑・置けない所は赤）、そこがワープ地点になります。なまえもつけられます。保存はお使いのブラウザの中だけです（前の版とは別に保存されます）。
- **カメラボタン**: いまの画面を写真にします。

## 技術メモ
静的ファイルだけ（ビルド不要）。`npx serve` や `node server.mjs` で開けます。モデルは骨組み付きの軽量 GLB（`assets/mochita_rigged.glb`、待機・歩き・走り）。

## アプリとして使う
Chrome（パソコン・Android）で開くと、アドレスバーの右に「インストール」のアイコンが出ます。押すと、アイコン付きのアプリとして開けます。iPhone の Safari は、共有ボタン →「ホーム画面に追加」です。

## おんがく
ブラウザの中で演奏するオルゴール風のオリジナル曲（やわらかい鈴の音で、伴奏の音数がゆっくり変わり、約3分50秒でひとめぐり）が、最初に画面をさわったときから流れます。右上の音符ボタンで ON/OFF できます。`?bgm=0` を付けると、最初から OFF で開きます。
